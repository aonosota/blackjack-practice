# 🃏 ブラックジャック ストラテジー練習

ベーシックストラテジーを身につけるためのブラウザ練習アプリです。
サーバー不要。`index.html` をブラウザで開くだけで動作します。

## デモ

**GitHub Pages で公開中 → [https://aonosota.github.io/blackjack-practice/](https://aonosota.github.io/blackjack-practice/)**

ブラウザからそのまま利用できます。インストール不要。

## 特徴

- 有限デッキの組み合わせ解析で求めた**EV（期待値）**でアクションを判定
- ミスを**EV損失の大きさ**で「惜しい / 不正解 / 重大なミス」に分類し、損失額（円）も表示
- ハンド終了後に**多角的な分析**と**ストラテジー表**を表示（アクションごとの即時フィードバックも選択可）
- ルール設定（デッキ数・S17/H17・DAS・サレンダー・再スプリット）に応じて推奨アクションが変化
- **練習モード**: ハード / ソフト / ペアのみ、全マス均等、苦手なマス優先で出題
- **弱点マップ**: マスごとの正解率をブラウザに保存し、ヒートマップで表示（セッションをまたいで蓄積）
- **インシュランス / イーブンマネー**の判断も練習・評価
- **上級モード**: 3枚以上の16 vs T など、構成依存の例外も正解として扱う
- プレイ記録を**CSV（BOM付きUTF-8）**でダウンロード可能

## 使い方

1. `index.html` をブラウザで開く
2. 必要に応じて設定を変更し「設定を適用」
3. 「セッション開始」でスタート
4. ベットを設定して「ディール」
5. ヒット・スタンド・ダブル・スプリット・サレンダーを選択
6. ハンド終了後に分析とストラテジー表を確認
7. 「セッション終了 & CSV保存」でプレイ記録をダウンロード

## ルール設定

| 設定 | 選択肢 | デフォルト |
|------|--------|-----------|
| デッキ数 | 1 / 2 / 4 / **6** / 8 | 6デッキ |
| ディーラーのソフト17 | **S17**（スタンド） / H17（ヒット） | S17 |
| DAS（スプリット後ダブル） | **あり** / なし | あり |
| サレンダー | **なし** / あり（レイトサレンダー） | なし |
| 再スプリット | **4ハンドまで**（Aは不可） / なし | 4ハンドまで |
| 開始チップ | 任意（最小100） | ¥10,000 |
| 最小/最大ベット | 任意 | ¥500 / ¥10,000 |
| 練習モード | **通常** / ハードのみ / ソフトのみ / ペアのみ / 全マス均等 / 苦手なマス優先 | 通常 |
| フィードバック | **ハンド終了後** / アクションごとに即時 | ハンド終了後 |
| 判定の基準 | **ベーシックストラテジー** / 上級（構成依存の例外を含む） | ベーシックストラテジー |

練習モードではディーラーのブラックジャックは出題しません（判断の練習に集中するため）。
チップが最小ベットを下回るとセッションは自動で終了します。

## 判定の仕組み

戦略表は手書きではなく、`tools/generate-strategy-data.js` が計算した EV 表（`js/strategy-data.js`）から
「EV が最大のアクション」として導出しています。6デッキの表は一般に公開されているベーシックストラテジー表と一致します。

- 不正解でも推奨との EV 差が **1%未満**なら「△ 惜しい（境界ケース）」、**5%以上**なら「重大なミス」
- インシュランスは「ホールカードが10の確率 < 1/3」なので常に断るのが正解
- ルールを追加・変更したら、次のコマンドで EV 表を作り直します（数十秒かかります）

```bash
node tools/generate-strategy-data.js
```

## ハンド分析

ハンド終了後に以下の情報が表示されます。

- ✅ / ❌ / △ の正誤判定（EV損失による重さ付き）
- 推奨アクションとその理由
- 各アクションの EV と、あなたの選択による期待損失
- 境界ケース（EV差が僅かな局面）の注記
- ルール変更（S17/H17・DAS・サレンダー・デッキ数）による推奨の違い
- 上級モードでの構成依存の例外
- よくある間違いの指摘
- 現在のルール設定を反映した**ストラテジー表**（該当セルをハイライト）

## CSV 記録フォーマット

| 列 | 内容 |
|----|------|
| 日時 | アクション発生時刻 |
| ハンド番号 / アクション番号 | セッション内の連番 |
| ディーラーオープンカード | ディーラーのアップカード |
| プレイヤーカード / 合計 / ハンド種別 | プレイヤーの手札情報 |
| 取ったアクション / 推奨(表記) / 推奨(実行可能) / 評価 | アクション判定 |
| デッキ数 / ディーラールール / DAS / サレンダー | ルール設定 |
| ベット額 / ハンド結果 / 収支 | 金額情報 |
| EV損失（ベット比% / 円） | 推奨アクションとの期待値の差 |
| 再スプリット / 練習モード | 設定 |

## 開発

### テスト

Node.js 18 以上が必要です。

```bash
npm test
```

`test/` 配下に `node:test` ベースのユニットテストがあります。ストラテジー表の検証（6デッキの全マス・1/2デッキの差分）、EV 評価、ゲームロジック（精算・再スプリット・インシュランス）、練習モード・弱点記録を網羅しています。依存パッケージは不要です。

## ファイル構成

```
blackjack_practice/

├── css/
│   └── style.css     # カジノ風 UI スタイル

│   ├── analysis.js   # ハンド後分析テキスト生成

│   ├── progress.js   # 弱点記録（localStorage）・練習モードの出題
│   └── main.js       # UI コントローラー・ゲームフロー
├── tools/
│   ├── bj-calc.js    # 有限デッキの EV 計算エンジン
│   └── generate-strategy-data.js # js/strategy-data.js の生成
└── test/
    ├── helpers.js    # Node でのモジュール読み込みヘルパー
    ├── strategy.test.js
    ├── game.test.js
    ├── settings.test.js
    ├── ev.test.js
    └── features.test.js
```

## アクションコード（ストラテジー表）

| コード | 意味 |
|--------|------|
| H | ヒット |
| S | スタンド |
| D | ダブルダウン（できなければヒット） |
| Ds | ダブルダウン（できなければスタンド） |
| P | スプリット |
| R | サレンダー（できなければヒット） |
| Rs | サレンダー（できなければスタンド） |
| Rp | サレンダー（できなければスプリット） |
| I / E / N | インシュランスを取る / イーブンマネーを受ける / 断る |
